# Методология исследования прогностического потенциала медиаданных

## 1. Общая методология

### 1.1 Цель исследования
Определение способности медиаданных сигнализировать о предстоящих кризисных событиях через анализ нарративных сдвигов в медиаполе.

### 1.2 Метод сбора данных
Сбор медиаматериалов осуществлялся с использованием автоматизированных парсеров, обрабатывающих открытые источники информации. Парсеры извлекали заголовки, даты публикации, источники и краткие описания материалов по заданным тематическим запросам.

**Технический стек:**
- Парсеры веб-контента для сбора материалов из открытых источников
- Модули обработки RSS-лент медиаресурсов
- Скрипты нормализации и дедупликации данных

### 1.3 Методология PRISMA
Процесс сбора и отбора материалов соответствует принципам PRISMA:

**Этап 1: Идентификация**
- Формирование поисковых запросов для каждого кейса
- Извлечение материалов из международных и российских источников
- Первичный сбор материалов (identification)

**Этап 2: Скрининг**
- Удаление дубликатов по хеш-сумме (title + date + source)
- Фильтрация по критериям релевантности
- Проверка дат публикации

**Этап 3: Пригодность**
- Оценка авторитетности источника
- Проверка на соответствие тематике кейса
- Исключение нерелевантных материалов

**Этап 4: Включение**
- Формирование итогового корпуса
- Аннотирование по нарративным стадиям
- Расчёт аналитических коэффициентов

## 2. Шкала нарративных стадий (N0-N5)

### Стадия N0: Норма
Период до проблематизации события. Тема не освещается или упоминается в нейтральном контексте без признаков кризиса. Материалы данной стадии потенциально содержат прогностические сигналы.

### Стадия N1: Первичная проблематизация
Появление первых сообщений о проблеме. Единичные публикации, не привлекающие широкого внимания. Осознание необычности ситуации без масштабной реакции.

### Стадия N2: Устойчивая проблематизация
Регулярное освещение темы в медиа. Осознание масштаба ситуации. Привлечение внимания общественности и экспертов. Накопление информации о проблеме.

### Стадия N3: Персонализация ответственности
Поиск конкретных виновников. Критика отдельных лиц или организаций. Формирование нарратива об ответственности. Эмоциональная окраска материалов.

### Стадия N4: Системный кризис
Максимальная эскалация. Конфликт выходит на системный уровень. Обсуждение фундаментальных проблем. Международный резонанс. Множественные конкурирующие нарративы.

### Стадия N5: Разрешение
Завершение острой фазы. Нормализация нарратива. Подведение итогов. Возврат к рутинному освещению темы.

## 3. Аналитические коэффициенты

### 3.1 source_type_scale (Тип источника)
Шкала от 0.5 до 1.0, отражающая авторитетность и тип источника:
- **1.0**: Официальные государственные источники (kremlin.ru, government.ru, whitehouse.gov и др.)
- **0.8**: Крупные международные агентства (Reuters, AP, BBC, Bloomberg, FT)
- **0.75**: Деловые издания (Коммерсантъ, Ведомости, Forbes)
- **0.7**: Государственные медиа (ТАСС, РИА, РБК)
- **0.5**: Прочие источники

### 3.2 article_tone (Тональность материала)
Классификация общей тональности материала:
- **critical**: Материал содержит критику, обвинения, негативную оценку
- **informational**: Нейтральное информирование без выраженной оценки
- **positive**: Позитивная оценка, решения, достижения
- **neutral**: Нейтральная тональность без явных маркеров

### 3.3 situation_presentation (Подача ситуации)
Характер представления ситуации в материале:
- **critical**: Акцент на проблемах, угрозах, кризисе
- **informational**: Объективное изложение фактов
- **positive**: Акцент на решениях, успехах, позитивных аспектах

### 3.4 forecast_presence (Наличие прогноза)
Бинарный признак наличия прогнозных оценок в материале:
- **true**: Материал содержит прогнозы развития ситуации
- **false**: Прогнозы отсутствуют

### 3.5 forecast_type (Тип прогноза)
При наличии прогноза:
- **positive**: Прогнозирует улучшение ситуации
- **negative**: Прогнозирует ухудшение ситуации

### 3.6 forecast_detail_level (Уровень детализации прогноза)
- **specific**: Конкретные прогнозы с указанием сроков, цифр, ответственных
- **general**: Общие прогнозы без конкретики

## 4. Структура данных

### 4.1 Формат CSV
Корпус представлен в формате CSV со следующими полями:

| Поле | Описание | Тип |
|------|----------|-----|
| id | Уникальный идентификатор | string |
| case_id | Идентификатор кейса | string |
| title | Заголовок материала | string |
| source | Источник | string |
| url | Ссылка на материал | string |
| date | Дата публикации | YYYY-MM-DD |
| snippet | Краткое содержание | string |
| block | Блок источников | international/russian |
| narrative_stage | Нарративная стадия | N0-N5 |
| source_type_scale | Коэффициент источника | float |
| article_tone | Тональность материала | string |
| situation_presentation | Подача ситуации | string |
| forecast_presence | Наличие прогноза | boolean |
| forecast_type | Тип прогноза | string |
| forecast_detail_level | Детализация прогноза | string |
| hash | Хеш для дедупликации | string |

## 5. Ограничения методологии

1. **Ограниченность источников**: Корпус ограничен доступными открытыми источниками и может не охватывать все релевантные материалы.

2. **Субъективность аннотирования**: Определение нарративных стадий основано на эвристических правилах и может содержать погрешности.

3. **Языковой охват**: Корпус включает материалы на русском и английском языках, другие языки не охвачены.

4. **Временные рамки**: Корпус ограничен определёнными датами и может не включать более поздние или ранние материалы.

## 6. Этические принципы

- Все материалы собраны из открытых источников
- Соблюдается авторство материалов (указание источника и ссылки)
- Корпус используется исключительно в исследовательских целях
- Персональные данные не собираются и не обрабатываются
