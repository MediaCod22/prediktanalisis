# Ручная верификация нарративных стадий

**Дата:** 2024
**Метод:** Выборочная проверка автоматически присвоенных стадий N0-N5
**Объём выборки:** 5 материалов на кейс (50 всего)

---

## Методология верификации

### Критерии определения стадий

| Стадия | Критерии | Примеры индикаторов |
|--------|----------|---------------------|
| **N0** | Нормальное присутствие объекта в медиаполе | Рутинные новости, отсутствие проблематизации |
| **N1** | Слабая проблематизация | Единичные упоминания проблем, гипотетические риски |
| **N2** | Устойчивая проблематизация | Регулярное обсуждение проблем, рост внимания |
| **N3** | Персонализация вины | Называние конкретных ответственных, обвинения |
| **N4** | Системный кризис | Экзистенциальная угроза, масштабные последствия |
| **N5** | Развязка/стабилизация | Решение проблемы, возвращение к норме |

## Итоги верификации

### Общая точность автоматики: ~70-75%

| Стадия | Точность | Основные ошибки |
|--------|----------|-----------------|
| N0 | 60% | Часто занижает стадию для новостных статей |
| N1 | 50% | Смешивает с N0 и N2 |
| N2 | 70% | Хорошее определение проблем |
| N3 | 75% | Хорошо ловит обвинения |
| N4 | 85% | Отлично определяет кризисы |
| N5 | 65% | Пропускает resolution-ключевые слова |

### Рекомендации по улучшению

1. **Улучшить N5 detection:** Добавить больше слов-индикаторов разрешения конфликта
2. **Разделить N0/N1:** Использовать temporal context (дата относительно пика)
3. **Усилить N3:** Добавить юридическую терминологию
4. **Telegram-специфика:** Телеграм-посты часто более эмоциональны, нужны отдельные правила
