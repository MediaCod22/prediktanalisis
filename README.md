# Прогностический потенциал медиаданных

Исследование способности медиаматериалов сигнализировать о предстоящих кризисных событиях через анализ нарративных сдвигов.

## Описание проекта

Проект представляет собой корпус медиаматериалов с аннотациями по нарративным стадиям (N0-N5). Цель исследования — определить, способны ли медиаданные содержать ранние сигналы кризисных событий.

## Исследуемые кейсы

| Кейс | Период | Материалов | Тип кризиса |
|------|--------|------------|-------------|
| Взрывы на «Северном потоке» | 09.2022 - настоящее время | 248 | Энергетический |
| Норильская авария (Норникель) | 05.2020 - 12.2021 | 296 | Экологический + корпоративный |

**Итого: 544 материала**

## Методология

### Шкала нарративных стадий

- **N0**: Норма — отсутствие проблематизации
- **N1**: Первичная проблематизация
- **N2**: Устойчивая проблематизация
- **N3**: Персонализация ответственности
- **N4**: Системный кризис
- **N5**: Разрешение

## Результаты исследования

### Ключевые выводы

1. **Прогностический потенциал зависит от типа кризиса**
   - Для техногенных катастроф с системными предпосылками — медиаданные могут содержать ранние сигналы
   - Для целенаправленных действий ограниченного круга лиц — прогностический потенциал ограничен

2. **Стадия N0 как индикатор**
   - Наличие материалов стадии N0 (без проблематизации) может указывать на скрытые системные риски
   - В кейсе «Норникель» такие материалы присутствуют, в «Северный поток» — отсутствуют

3. **Различия в динамике нарративов**
   - «Северный поток»: пики на N2-N3 (реактивное освещение)
   - «Норникель»: выраженная стадия N4 (системный кризис)

## Аналитические коэффициенты

Для каждого материала рассчитаны:
- **source_type_scale**: Авторитетность источника (0.5-1.0)
- **article_tone**: Тональность (critical/informational/positive)
- **situation_presentation**: Подача ситуации
- **forecast_presence**: Наличие прогнозов
- **forecast_type**: Тип прогноза
- **forecast_detail_level**: Детализация прогноза

## Лицензия

Корпус собран из открытых источников в исследовательских целях. Все материалы сохраняют авторство оригинальных источников.
