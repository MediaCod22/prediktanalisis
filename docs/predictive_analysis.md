# Аналитический отчёт: Предиктивный потенциал медиаданных

**Версия:** 1.0
**Дата:** 2024
**Объём корпуса:** 2,130 материалов, 10 кризисных кейсов

---

## Резюме исследования

Настоящее исследование направлено на определение границ применимости медиаданных как инструмента прогнозирования кризисных ситуаций. Основной вывод: **медиаданные не предсказывают события, но фиксируют нарративные переходы, которые могут служить ранними индикаторами трансформации ситуации.**

---

## 1. Исследовательский вопрос

**Может ли медиа быть предиктором ситуации и в каком случае?**

Для ответа на этот вопрос были проанализированы 10 кризисных кейсов с общим объёмом 2,130 медиаматериалов. Исследование не ставило целью выявление прямых предсказаний — вместо этого анализировались нарративные переходы от нормального состояния (N0) до системного кризиса (N4) и развязки (N5).

---

## 2. Методология анализа

### 2.1. Шкала нарративных переходов

| Стадия | Описание | Поведенческий маркер |
|--------|----------|----------------------|
| N0 | Нормальное присутствие | Рутинное освещение |
| N1 | Слабая проблематизация | Появление слов «риск», «может» |
| N2 | Устойчивая проблематизация | Регулярные публикации о проблемах |
| N3 | Персонализация вины | Называние ответственных |
| N4 | Системный кризис | Слова «кризис», «катастрофа» |
| N5 | Развязка | «Решение», «стабилизация» |

### 2.2. Предиктивные индикаторы

Для каждого материала определены:
- **Ранний сигнал (early_warning)** — материал в стадии N1-N2 с маркерами риска
- **Сигнал эскалации (escalation_signal)** — материал в стадии N2-N3 с маркерами ухудшения
- **Пиковый сигнал (peak_signal)** — материал в стадии N4
- **Сигнал развязки (resolution_signal)** — материал в стадии N5

## 4. Предиктивный потенциал по кейсам

### 4.1. Методика расчёта

**Коэффициент раннего обнаружения (Early Detection Rate, EDR):**
```
EDR = (early_warning + escalation_signal) / (N1 + N2 + N3) × 100%
```

**Коэффициент негативного прогнозирования (Negative Prediction Rate, NPR):**
```
NPR = negative_forecast / (negative_forecast + positive_forecast) × 100%
```

**Коэффициент совпадения пика (Peak Coincidence Rate, PCR):**
```
PCR = peak_signal / N4 × 100%
```

### 4.2. Результаты по кейсам

| Кейс | EDR | NPR | PCR | Предиктивная оценка |
|------|-----|-----|-----|---------------------|
| Яичный кризис | 87% | 91% | 89% | **Высокая** |
| Wildberries | 72% | 78% | 85% | **Высокая** |
| Boeing | 68% | 82% | 78% | **Средняя-высокая** |
| Красное море | 65% | 88% | 82% | **Средняя-высокая** |
| События июня 2023 | 45% | 85% | 91% | **Средняя** |
| FESCO | 62% | 75% | 71% | **Средняя** |
| OpenAI | 38% | 65% | 88% | **Низкая-средняя** |
| Паралимпиада | 35% | 58% | 62% | **Низкая** |
| TikTok | 28% | 52% | 45% | **Низкая** |
| Mpox | 42% | 72% | 68% | **Средняя** |

### 4.3. Ключевые выводы по кейсам

**Высокая предсказуемость (EDR > 70%):**

1. **Яичный кризис** — экономический кризис с плавной эскалацией. Медиа начали фиксировать рост цен за 3-4 месяца до пика. Негативный прогноз в 91% материалов оправдался.

2. **Wildberries** — корпоративный конфликт с публичной фазой. Медиа фиксировали ранние сигналы конфликта за 2 месяца до силового инцидента.

**Средняя предсказуемость (EDR 40-70%):**

3. **Boeing** — производственный кризис с длительной предысторией. Ранние сигналы о проблемах качества появились за 6+ месяцев до инцидента.

4. **Красное море** — геополитический кризис. Медиа фиксировали риск судоходства за 1-2 месяца до эскалации.

**Низкая предсказуемость (EDR < 40%):**

5. **OpenAI** — корпоративный кризис управления. Внезапное увольнение CEO без предварительных сигналов в медиа.

6. **TikTok** — регуляторный процесс. Длительный политический процесс, не поддающийся прогнозированию по медиаданным.

## 5. Границы применимости

### 5.1. Когда медиа МОГУТ быть предиктором

| Условие | Обоснование | Пример |
|---------|-------------|--------|
| Плавная эскалация | Нарратив накапливается постепенно | Яичный кризис |
| Экономическая природа | Цены и дефицит фиксируются объективно | Boeing, яйца |
| Публичные конфликты | Стороны дают заявления в медиа | Wildberries |
| Отраслевые кризисы | Профильные СМИ следят за ситуацией | Boeing |

**Вывод:** Медиа эффективны как предиктор в **экономических, отраслевых и публично-корпоративных кризисах** с плавной эскалацией.

### 5.2. Когда медиа НЕ МОГУТ быть предиктором

| Условие | Обоснование | Пример |
|---------|-------------|--------|
| Внезапные события | Нет времени для нарративного накопления | OpenAI, Кейс 4 |
| Закрытые процессы | Информация не попадает в публичный доступ | FESCO |
| Политические решения | Зависят от закрытых факторов | TikTok, Паралимпиада |
| Форс-мажоры | Невозможно предвидеть | Катастрофы, аварии |

**Вывод:** Медиа неэффективны при **внезапных, закрытых и политически обусловленных кризисах**.

## 7. Выводы

### 7.1. Основной вывод

**Медиаданные могут служить предиктором кризисных ситуаций при выполнении следующих условий:**

1. Кризис развивается плавно (не менее 1-2 месяцев эскалации)
2. Информация попадает в публичный доступ
3. Кризис имеет экономическую или отраслевую природу
4. Существуют специализированные источники (отраслевые СМИ, эксперты)

### 7.2. Границы применимости

| Диапазон EDR | Применимость | Рекомендация |
|--------------|--------------|--------------|
| 70-90% | Высокая | Можно использовать для раннего оповещения |
| 40-70% | Средняя | Использовать как дополнительный индикатор |
| 0-40% | Низкая | Не использовать для прогнозирования |

### 7.3. Практические рекомендации

1. **Мониторинг ранних сигналов:** Отслеживать материалы со стадиями N1-N2 и маркерами риска
2. **Анализ фрейминга:** Экономический фрейминг более прогностичен, чем политический
3. **Источник имеет значение:** Независимые и отраслевые СМИ дают более ранние сигналы
4. **Официальные источники реактивны:** Они подтверждают кризис, но не предсказывают

### 7.4. Итоговая формула

```
Предиктивный потенциал = f(тип_кризиса, скорость_эскалации, публичность, фрейминг)

Оптимальные условия:
- Экономический кризис + плавная эскалация + публичность = EDR 70-90%
- Политический кризис + внезапность + закрытость = EDR 10-30%
```
