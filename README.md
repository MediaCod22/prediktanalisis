# Прогностический потенциал медиаданных

Исследование способности медиаматериалов сигнализировать о предстоящих кризисных событиях через анализ нарративных сдвигов.

## Описание проекта

Проект представляет собой корпус медиаматериалов с аннотациями по нарративным стадиям (N0-N5). Цель исследования — определить, способны ли медиаданные содержать ранние сигналы кризисных событий.

**Общий объём корпуса: 2 728 материалов**

## Методология

### Шкала нарративных стадий (N0-N5)

| Стадия | Название | Описание |
|--------|----------|----------|
| **N0** | Норма | Отсутствие проблематизации, рутина |
| **N1** | Первичная проблематизация | Единичные сигналы, локальное внимание |
| **N2** | Устойчивая проблематизация | Регулярное освещение, рост внимания |
| **N3** | Персонализация | Поиск виновных, обвинения |
| **N4** | Системный кризис | Масштабный резонанс, эскалация |
| **N5** | Разрешение | Нормализация, затухание интереса |

### Технические средства сбора

Для сбора медиаматериалов использовались open-source инструменты:
- **Newspaper3k** — извлечение статей из веб-источников
- **Feedparser** — парсинг RSS/Atom лент
- **Scrapy** — веб-краулинг
- **BeautifulSoup** — HTML-парсинг

### Методология PRISMA

Сбор данных соответствовал принципам PRISMA:
1. **Идентификация** — формирование поисковых запросов
2. **Скрининг** — удаление дубликатов, фильтрация по релевантности
3. **Пригодность** — оценка авторитетности источников
4. **Включение** — аннотирование и расчёт коэффициентов

Подробнее: [docs/methodology.md](docs/methodology.md)

## Результаты исследования

### Ключевые выводы

1. **Прогностический потенциал зависит от типа кризиса**
   - Высокий: регуляторные процессы, повторяющиеся события (TikTok, Mpox)
   - Средний: системные проблемы с предвестниками (Boeing, Норникель)
   - Низкий: внезапные события ограниченного круга лиц (Wagner, Северный поток)

2. **Стадия N0 как индикатор**
   - Наличие материалов без проблематизации указывает на скрытые риски
   - Выявлено в кейсах: Mpox, Норникель, TikTok

3. **Различия в динамике нарративов**
   - Глобальные кризисы: более длительная стадия N2-N3
   - Корпоративные конфликты: быстрая эскалация до N4
   - Регуляторные процессы: растянутый цикл N1-N5

### Аналитические коэффициенты

Для каждого материала рассчитаны:
- **source_type_scale** — Авторитетность источника (0.5-1.0)
- **article_tone** — Тональность (critical/informational/positive)
- **narrative_stage** — Нарративная стадия (N0-N5)
- **forecast_presence** — Наличие прогнозов
