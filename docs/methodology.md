# Методология исследования прогностического потенциала медиаданных

## 1. Общая методология исследования

### 1.1 Цель и задачи исследования

**Цель исследования** — определение способности медиаданных сигнализировать о предстоящих кризисных событиях через анализ нарративных сдвигов в медиаполе.

**Задачи исследования:**
1. Сформировать репрезентативный корпус медиаматериалов по кризисным событиям различного типа
2. Разработать методологию аннотирования материалов по нарративным стадиям
3. Проанализировать динамику нарративов в предшествующий и последующий периоды
4. Оценить прогностический потенциал медиаданных для различных типов кризисов

### 1.2 Методология PRISMA

Сбор и отбор материалов осуществлялся в соответствии с методологией PRISMA (Preferred Reporting Items for Systematic Reviews and Meta-Analyses). Процесс включал четыре этапа:

**Этап 1: Идентификация (Identification)**
- Формирование поисковых запросов для каждого кейса на основе ключевых событий и дат
- Определение релевантных источников по категориям (международные, российские, официальные)
- Извлечение материалов с использованием автоматизированных средств сбора

**Этап 2: Скрининг (Screening)**
- Удаление дубликатов по хеш-сумме (заголовок + дата + источник)
- Фильтрация по критериям релевантности тематике кейса
- Проверка дат публикации на соответствие временному окну

**Этап 3: Пригодность (Eligibility)**
- Оценка авторитетности источника по шкале source_type_scale
- Проверка полноты метаданных (наличие заголовка, даты, источника)
- Исключение материалов с неполными или некорректными данными

**Этап 4: Включение (Included)**
- Формирование итогового корпуса с аннотациями
- Расчёт аналитических коэффициентов для каждого материала
- Валидация выборки на репрезентативность

## 2. Технические средства сбора данных

### 2.1 Используемые инструменты

Для сбора медиаматериалов использовались следующие open-source инструменты:

**Newspaper3k** — open-source библиотека для извлечения статей из веб-источников. Инструмент обеспечивает автоматическое извлечение заголовков, текста, метаданных и изображений из новостных статей. Newspaper3k поддерживает работу с множеством языков, включая русский и английский, и активно используется в академических исследованиях медиапространства.

**Feedparser** — open-source парсер RSS/Atom лент, применявшийся для сбора материалов из новостных агрегаторов и медиаресурсов, предоставляющих RSS-ленты. Инструмент обеспечивает структурированное извлечение заголовков, дат публикации, описаний и ссылок.

**Requests + BeautifulSoup** — комбинация open-source библиотек для HTTP-запросов и парсинга HTML-страниц. Применялась для сбора материалов с ресурсов, не предоставляющих RSS-ленты, а также для извлечения материалов из официальных источников (правительственные сайты, документы международных организаций).

**Scrapy** — open-source фреймворк для веб-скрейпинга, использовавшийся для масштабного сбора материалов из множественных источников с соблюдением правил robots.txt и ограничений на частоту запросов.

### 2.2 Принципы выбора источников

Выбор источников осуществлялся по следующим критериям:

**Категория A: Международные новостные агентства**
- Рейтинги Trust Project и NewsGuard
- Минимум 5 лет активной работы
- Наличие редакционной политики и коррекционной практики
- Примеры: Reuters, Associated Press, BBC, The Guardian, Financial Times

**Категория B: Национальные медиа**
- Статус общенационального издания
- Тираж/аудитория более 1 млн
- Репутация среди профессионального сообщества
- Примеры: The New York Times, Wall Street Journal (США); Der Spiegel (Германия); ТАСС, РИА Новости, Коммерсантъ (Россия)

**Категория C: Официальные источники**
- Правительственные сайты (.gov, .gouv, government.ru)
- Документы международных организаций (UN, WHO, EU)
- Судебные документы и законодательные акты
- Примеры: congress.gov, kremlin.ru, who.int

**Категория D: Отраслевые и специализированные издания**
- Профильная экспертиза в соответствующей области
- Признание профессиональным сообществом
- Примеры: Aviation Week (авиация), Lloyd's List (морские перевозки)

### 2.3 Методы сбора данных

**Метод 1: Поисковые запросы**
Формирование поисковых запросов на основе ключевых слов и фраз, релевантных каждому кейсу. Запросы составлялись на английском и русском языках с учётом специфики медиаландшафта.

**Метод 2: Временные окна**
Для каждого кейса определялись временные окна сбора:
- Предкризисный период: материалы за 3-6 месяцев до события
- Кризисный период: материалы во время острой фазы
- Посткризисный период: материалы после разрешения

**Метод 3: Снежный ком**
От базовых источников осуществлялся переход по ссылкам на релевантные материалы, что позволяло выявить дополнительные источники и расширить охват.

## 3. Шкала нарративных стадий (N0-N5)

### 3.1 Описание шкалы

Разработанная шкала нарративных стадий отражает эволюцию проблемы в медиаполе:

| Стадия | Название | Описание | Индикаторы |
|--------|----------|----------|------------|
| **N0** | Норма | Отсутствие проблематизации | Нейтральное освещение, рутина |
| **N1** | Первичная проблематизация | Первые сигналы | Единичные материалы, локальное внимание |
| **N2** | Устойчивая проблематизация | Регулярное освещение | Серия публикаций, рост внимания |
| **N3** | Персонализация | Поиск виновных | Обвинения, критика конкретных лиц |
| **N4** | Системный кризис | Эскалация | Масштабный резонанс, системная критика |
| **N5** | Разрешение | Нормализация | Подведение итогов, затухание интереса |

### 3.2 Методология аннотирования

Аннотирование материалов по нарративным стадиям проводилось по следующим правилам:

1. **Определение временного контекста** — дата публикации материала соотносится с хронологией событий кейса
2. **Анализ содержания** — оценка тональности, наличия обвинений, уровня проблематизации
3. **Определение стадии** — присвоение метки N0-N5 на основе индикаторов
4. **Валидация** — проверка соответствия аннотации общему контексту кейса

## 4. Аналитические коэффициенты

### 4.1 source_type_scale (Тип источника)

Шкала авторитетности источника от 0.5 до 1.0:

| Значение | Тип источника | Примеры |
|----------|---------------|---------|
| 1.0 | Официальные государственные | kremlin.ru, congress.gov, who.int |
| 0.8 | Международные агентства | Reuters, AP, BBC, Bloomberg |
| 0.75 | Деловые издания | Коммерсантъ, Ведомости, FT |
| 0.7 | Национальные медиа | ТАСС, РИА, NYT, Guardian |
| 0.5 | Прочие источники | Блоги, региональные СМИ |

### 4.2 article_tone (Тональность материала)

Классификация общей тональности:

- **critical** — критика, обвинения, негативная оценка
- **informational** — нейтральное информирование
- **positive** — позитивная оценка, решения, успехи
- **neutral** — отсутствие явной эмоциональной окраски

### 4.3 forecast_presence (Наличие прогноза)

Признак наличия прогнозных оценок в материале:

- **true** — материал содержит прогнозы развития ситуации
- **false** — прогнозы отсутствуют

При наличии прогноза указываются:
- **forecast_type** — тип прогноза (positive/negative)
- **forecast_detail_level** — уровень детализации (specific/general)

## 5. Структура данных

### 5.1 Формат корпуса

Корпус представлен в формате CSV со следующими полями:

| Поле | Описание | Тип |
|------|----------|-----|
| case_id | Идентификатор кейса | string |
| case_name | Название кейса | string |
| case_type | Тип кейса (global/russian) | string |
| material_id | Уникальный ID материала | string |
| source_name | Название источника | string |
| source_country | Страна источника | string |
| source_language | Язык материала | string |
| source_block | Блок источников | string |
| source_type | Тип источника | string |
| published_at | Дата публикации | string |
| title | Заголовок материала | string |
| url | Ссылка на материал | string |
| description | Краткое описание | string |
| narrative_stage | Нарративная стадия | string |
| sentiment | Сентимент материала | string |
| anxiety_level | Уровень тревожности | int |
| frame_type | Тип фрейминга | string |
| blame_present | Наличие обвинений | boolean |
| systemic_risk | Системный риск | boolean |

## 6. Этические принципы и ограничения

### 6.1 Этические принципы

- Все материалы собраны из открытых источников
- Соблюдается авторство материалов с указанием источника и ссылок
- Корпус используется исключительно в исследовательских целях
- Персональные данные не собираются и не обрабатываются
- Соблюдаются правила robots.txt и ограничения источников

### 6.2 Ограничения методологии

1. **Ограниченность источников** — корпус ограничен доступными открытыми источниками
2. **Языковой охват** — корпус включает материалы на русском и английском языках
3. **Временные рамки** — охват ограничен периодом активного освещения события
4. **Субъективность аннотирования** — определение нарративных стадий содержит элемент интерпретации
