**Версия:** 2.0
**Дата:** 2024

---

## 1. Концептуальная рамка исследования

### 1.1. Основной исследовательский вопрос

**Могут ли медиаданные выступать предиктором кризисных ситуаций и в каких границах применима такая прогностика?**

Исследование не ставит целью выявление прямых предсказаний событий. Вместо этого анализируются **нарративные переходы** — трансформации того, как объект исследования представлен в публичном медиаполе.

### 1.2. Шкала нарративных переходов

| Код | Стадия | Описание | Индикаторы |
|-----|--------|----------|------------|
| N0 | Нормальное присутствие | Рутинное освещение без проблематизации | Нейтральные заголовки, фактические отчёты |
| N1 | Слабая проблематизация | Единичные сигналы о проблемах | Слова-маркеры: «может», «потенциально», «риск» |
| N2 | Устойчивая проблематизация | Регулярное обсуждение проблем | Множественные публикации, рост частоты |
| N3 | Персонализация вины | Называние конкретных ответственных | Имена, обвинения, юридический язык |
| N4 | Системный кризис | Экзистенциальная угроза | «Кризис», «катастрофа», «крах», «чрезвычайная ситуация» |
| N5 | Развязка/стабилизация | Возвращение к норме | «Решение», «снижение», «восстановление», «договорённость» |

## 3. Методы сбора данных

### 3.1. Источники данных

#### 3.1.1. Международные новостные агрегаторы

Использованы публичные API новостных агрегаторов для сбора материалов из международных источников:

**Источники:**
- Агрегаторы новостного контента (NewsAPI-совместимые сервисы)
- Официальные сайты международных организаций (WHO, UN, Congress.gov)
- Архивы новостных агентств (Reuters, AP, AFP)

**Метод:** Программный парсинг через REST API с параметрами:
- `query`: ключевые слова кейса
- `from_date` / `to_date`: временные границы
- `language`: en/ru
- `page_size`: 20-25 материалов за запрос

#### 3.1.2. Российские СМИ

Сбор материалов из российских источников осуществлялся через:

**Сайты новостных агентств (10 основных):**
1. ТАСС (tass.ru) — государственное информагентство
2. РИА Новости (ria.ru) — государственное информагентство
3. Интерфакс (interfax.ru) — независимое информагентство
4. РБК (rbc.ru) — деловой портал
5. Коммерсант (kommersant.ru) — деловая газета
6. Ведомости (vedomosti.ru) — деловая газета
7. Forbes.ru — бизнес-издание
8. Российская газета (rg.ru) — государственная газета
9. Известия (iz.ru) — общественно-политическая газета
10. RT (rt.com) — международная сеть

**Метод:** 
- Парсинг через search-интерфейсы сайтов
- RSS-ленты (где доступны)
- Site-specific запросы к поисковым системам

#### 3.1.3. Telegram-каналы

**Типы документов:**

## 5. Алгоритмы аннотирования

### 5.1. Определение нарративной стадии

Автоматическое присвоение narrative_stage основано на анализе заголовка и сниппета:

```python
def estimate_narrative_stage(title, snippet):
    text = f"{title} {snippet}".lower()
    
    # N5 - развязка (проверяется первой)
    if any(kw in text for kw in ['resolved', 'reinstated', 'решение', 'стабилизация']):
        return 'N5'
    
    # N4 - системный кризис
    if any(kw in text for kw in ['crisis', 'emergency', 'mutiny', 'мятеж', 'катастрофа']):
        return 'N4'
    
    # N3 - персонализация
    if any(kw in text for kw in ['blame', 'arrest', 'суд', 'обвиня']):
        return 'N3'
    
    # N2 - устойчивая проблематизация
    if any(kw in text for kw in ['problem', 'risk', 'дефицит', 'рост цен']):
        return 'N2'
    
    # N1 - слабая проблематизация
    if any(kw in text for kw in ['may', 'could', 'может', 'возможн']):
        return 'N1'
    
    return 'N0'
```

### 5.2. Определение тональности

Анализ проводится по словарю позитивных и негативных маркеров:

**Негативные индикаторы:**
- crisis, crash, fail, disaster, attack, war, ban, arrest
- кризис, крах, провал, катастрофа, атак, арест, рост цен, дефицит

**Позитивные индикаторы:**
- success, resolve, solution, improve, growth, recovery
- успех, решение, улучш, рост, восстановл, снижение

### 5.3. Определение фрейма

Каждому материалу присваивается доминирующий фрейм на основе ключевых слов:

| Фрейм | Ключевые слова |
|-------|----------------|
| security | military, war, attack, missile, военн, войн, атак, мятеж |
| economic | price, cost, market, inflation, цен, рынок, экономик |
| legal | court, law, sue, arrest, суд, закон, иск, преступл |
| political | government, president, congress, правительств, президент |
| medical | health, disease, virus, vaccine, здоровь, болезн, вирус |
| managerial | ceo, board, management, директор, совет, управлен |
| sport | olympic, paralympic, athlete, олимпиад, паралимпиад, спортсмен |

## 6. Обеспечение качества данных

### 6.1. Дедупликация

**Алгоритм:**
1. Генерация MD5-хеша от строки: `title + date + source`
2. Проверка на существование хеша в базе
3. Для заголовков с сходством >80% — ручная проверка

**Результат:** 1,170 дубликатов удалено из 3,300 материалов (35.5%)

### 6.2. Валидация данных

- Проверка на пустые обязательные поля (title, url)
- Валидация формата даты
- Проверка URL на доступность (выборочная)

### 6.3. Ручная верификация

Выборочная проверка автоматической разметки:
- Объём выборки: 50 материалов (5 на кейс)
- Проверяемые атрибуты: narrative_stage, sentiment, frame_type
- Оценка точности: 70-75%

## 7. Ограничения методологии

### 7.1. Источниковые ограничения

- **Платные источники:** Недоступны материалы из платных архивов
- **Telegram:** Сбор ограничен публичными каналами
- **Региональные СМИ:** Ограниченное покрытие

### 7.2. Методологические ограничения

- **Автоматическая разметка:** Точность 70-75%, требует ручной верификации
- **Омонимия:** Возможны ложные срабатывания по ключевым словам
- **Временные метки:** Не все источники предоставляют точную дату публикации

### 7.3. Языковые ограничения

- Основные языки: русский, английский
- Материалы на других языках не включены
